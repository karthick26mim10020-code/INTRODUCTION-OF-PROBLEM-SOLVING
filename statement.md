# 📘 Project Statement  
## **Movies & Shows Management System**

### **1. Project Title**
Movies & Shows Management System (Python-Based CLI Project)

---

### **2. Problem Statement**
Managing personal collections of movies and TV shows becomes difficult when they grow large.  
People often forget:
- Which movies they have watched
- What shows they are currently watching
- Release years, durations, or number of episodes
- What they want to watch next

There is a need for a simple, offline, menu-based system that helps users store, organize, and track their entertainment content easily.

This project provides a solution by allowing users to add, view, search, update, and delete movies/shows in a structured and user-friendly manner.

---

### **3. Objectives of the Project**
- To design a menu-driven Python application using basic programming concepts.
- To store and manage movies and TV shows in a structured format.
- To allow users to:
  - Add movies separately
  - Add shows separately
  - View all saved content
  - Mark items as watched
  - Delete stored items
  - Search based on keywords
- To implement persistent storage using JSON files.
- To create a beginner-friendly Python project suitable for academic submissions.

---

### **4. Scope of the Project**
The project includes:
- Adding movies with title, year, duration, and genre  
- Adding shows with seasons, episodes, year, duration per episode  
- Saving all data into a JSON file  
- Viewing complete list of stored entries  
- Searching items using title keywords  
- Updating watch status  
- Deleting entries  

The project does **not** include:
- Online API integrations  
- GUI interface  
- Recommendation algorithms (can be added later)

---

### **5. Software & Language Used**
- **Programming Language:** Python 3  
- **Data Storage:** JSON file (`movies_shows.json`)  
- **Environment:** Any Python-supported editor  
  - VS Code  
  - PyCharm  
  - Pydroid3 (Android)  
  - IDLE  
  - Termux  

---

### **6. System Requirements**
- Python 3.x installed  
- Operating System:
  - Windows / macOS / Linux / Android  
- Basic terminal/command-line support  
- No internet required  

---

### **7. Functional Requirements**
1. The system must allow adding movies  
2. The system must allow adding shows  
3. The system must store:
   - Titles  
   - Years  
   - Durations  
   - Seasons & episodes (for shows)  
   - Watch status  
4. Data must save automatically in JSON  
5. User must be able to search items  
6. User must be able to delete items  
7. User must be able to mark items as watched
